# Design previews

Три варіанти головної сторінки сайту 3D-друку (прототипи, не продакшн).

- Відкрийте `index.html` у браузері (подвійний клік працює, інтернет не потрібен). Там три картки.
- `v1-obiem/` 3D-деталь, `v2-foto/` фоторедакційний, `v3-brand/` бирка з ціною.
- Знімки згенеровані як ілюстрації і позначені на сторінках. Ціни `[X]`, назва `[НАЗВА]`, контакти і форма заповнювачі.
- Шрифти і скрипти лежать у папках, зовнішніх запитів немає. Ліцензії шрифтів (SIL OFL) поруч зі шрифтами, ліцензії бібліотек у `v1-obiem/js/LICENSES.txt`.
- Сторінки закриті від індексації (`noindex`, `robots.txt`).
